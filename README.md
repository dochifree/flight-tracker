# 항공권 스크리닝 트래커 (무료 구성)

Google Flights 비공식 스크레이퍼(faster-flights)와 GitHub Actions로, 인천·김포 출발 **일본·동남아·대만** 직항 왕복 항공권을 계속 조회해
월별 CSV에 쌓고, 같은 노선·같은 항공사 유형의 평소 가격보다 크게 싸면 텔레그램으로 알립니다.
결과는 GitHub Pages 페이지(`index.html`)에서 노선별로 볼 수 있습니다.

## 동작 방식
- 실행: 하루 4회(한국 시간 00:07, 06:07, 12:07, 18:07). GitHub 사정으로 30~50분 늦게 시작할 수 있습니다. 수동 실행도 가능합니다.
- 조회 대상: 내일부터 90일 안의 출발일, 2~5박, **주말·공휴일이 2일 이상 낀 일정만**. 직항만.
- 조회 방식: 매 실행마다 조건에 맞는 일정을 **전부** 조회합니다(전수 조회). 한 작업으로는 5시간 넘게 걸려서 **8개 작업으로 나눠 동시에** 조회하고(`collect`), 결과를 합쳐서(`finalize`) 저장·알림·요약을 만듭니다. 작업 수를 바꾸려면 `track.yml`의 shard 목록과 `--shards`, `--expect` 숫자를 함께 바꾸세요.
- 새 노선은 직항 여부를 먼저 6건만 시험 조회해 보고, 결과가 있으면 다음 실행부터 전부 조회합니다.
- 편도 조합: 가는 편·오는 편 편도를 각각 조회해 합친 일정(항공사가 달라도 됨)도 함께 모읍니다. 전수가 아니라 일부 구간만 돌아가며 조회합니다. 각각 따로 예매해야 합니다.
- 연차: 출발일~귀국일 중 평일(공휴일 제외)의 수. 출발일·귀국일도 하루로 셉니다.
- 평소 가격: 같은 노선 + 같은 항공사 유형(저비용/대형/혼합)의 중앙값. 최근 60일 안에 조회했고 출발일이 지금 조회 범위 안인 가격만 씁니다.
- 알림: 연차 3일 이하 + 평소보다 30% 이상 저렴 + 같은 그룹 표본 6건 이상. 같은 일정은 14일 안에 비슷한 가격으로 반복 알리지 않습니다.
- 직항이 없는 노선은 5번 조회해 결과가 없으면 14일간 자동 제외됩니다.

## 결과 파일 (data 폴더)
- `deals.csv`: 알림 기록
- `summary.csv`: 노선·항공사 유형별 최저가 한 줄 요약
- `offers.csv`: 박수·연차별 최저가 (웹페이지 필터용)
- `prices-YYYY-MM.csv`: 조회된 모든 가격 기록(월별로 이어쓰기)
- `state.json`: 제외된 노선, 결과 없음 기록 등 내부 상태 (직접 고치지 않으셔도 됩니다)

## 설정 (routes.json)
- `origins`, `destinations`: 출발·도착 공항. 지역(일본·동남아·대만)을 통째로 빼거나 넣을 수 있습니다.
- `nights`: 박수 후보
- `start_offset_days`, `horizon_days`: 며칠 뒤부터, 며칠 범위의 출발일을 볼지
- `min_nonwork_days`: 일정에 낀 주말·공휴일 최소 일수
- `full_sweep`: true면 전수 조회(위 설명). false면 `queries_per_run`만큼만 오래된 일정부터 조회
- `oneway_queries_per_run`: 1회 실행당 편도 조합용 조회 건수, `pause_seconds`: 조회 간격
- `region_weight`: `full_sweep`이 false일 때만 쓰이는 지역별 조회 빈도 가중치
- `alert`: `ratio`(0.7 = 30% 이상 저렴), `min_samples`, `lookback_days`, `max_leave_days`
- `carrier_groups`: 항공사 이름을 저비용/대형으로 나눈 목록(목록에 없는 항공사는 그 항공사끼리만 비교)
- `holidays`: 공휴일 목록. **2027년 말까지만 들어 있으니 이후에는 추가해야 합니다.**

## 텔레그램 알림
저장소 Settings > Secrets and variables > Actions에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 등록합니다. 토큰은 채팅이나 화면 캡처에 노출하지 마세요.

## 주의
- 비공식 스크레이핑이라 Google 쪽 변경이나 차단으로 조회가 실패할 수 있습니다. 각 작업에서 연속 오류가 12번 나오면 그 작업은 멈추고, 일부만 끝나면 텔레그램으로 알려 드립니다.
- 가격은 직접 검색한 가격과 다를 수 있습니다. 이 도구는 "어디를 직접 검색해 볼지" 고르는 용도이며, 예약 전 항공사나 Google에서 최종 가격과 수하물 조건을 확인하세요.
- 평소 가격은 표본이 쌓여야 안정됩니다. 처음 며칠은 알림이 적거나 기준이 흔들릴 수 있습니다.
